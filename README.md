# Co-CEO — documentação de produto

Repositório de planejamento do Co-CEO, proposta de plataforma de IA para empreendedores. A visão documentada combina organização de contexto, preparação de decisões e execução supervisionada, com WhatsApp como interface principal do MVP.

## Estado deste repositório

Este repositório reúne seis documentos de planejamento do produto, sem código de aplicação, manifesto ou instruções de instalação. Funcionalidades, integrações com WhatsApp/Agenda, briefings e agentes são escopo planejado. A aprovação humana para ações sensíveis também faz parte desse planejamento.
